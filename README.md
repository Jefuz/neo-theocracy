# Neo-Theocracy

A text-based strategy game in the spirit of Civilization and Theocracy (2000). You play a shaman who truly reincarnates, guiding a tribe across centuries toward statehood. Play happens through questions put to you by petitioners, advisors, envoys and rivals; consequences surface lives later as shifts in which groups hold power.

## Running

The game is a single self-contained HTML file with no dependencies. Open `index.html` in a browser. Add `?debug=1` to the URL for data validation and headless bot simulations.
